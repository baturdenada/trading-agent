# Generate Daily Trading Report

## Step 1: Get Account Status
- action: get_account
- output: account_data

## Step 2: Generate Summary
- action: ai_summary
- input: |
  Current Balance: {{account_data.balance}}
  Current Equity: {{account_data.equity}}
  Today's PnL: {{account_data.profit}}
  Margin Used: {{account_data.margin}}
- prompt: "Summarize this trading account's daily performance. Mention any concerns or positive aspects. Keep it brief (3-4 sentences)."
- output: daily_summary

## Step 3: Create Report File
- action: write_file
- path: C:\trading-memory\obsidian-vault\Daily-Logs\Report_{{date}}.md
- content: |
  # Daily Trading Report
  **Date:** {{date}}
  
  ## Account Status
  - Balance: ${{account_data.balance}}
  - Equity: ${{account_data.equity}}
  - Daily PnL: ${{account_data.profit}}
  - Margin: ${{account_data.margin}}
  
  ## Summary
  {{daily_summary}}
  
  ## Next Actions
  Review performance and plan for tomorrow
  
  ---
  *Auto-generated by Workflow Engine*

## Step 4: Send Telegram Alert
- action: telegram_send
- message: |
  📊 DAILY REPORT - {{date}}
  
  💰 Balance: ${{account_data.balance}}
  💹 Daily PnL: ${{account_data.profit}}
  
  {{daily_summary}}
  
  📁 Full report saved to Obsidian
